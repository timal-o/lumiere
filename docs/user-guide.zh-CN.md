## 快速开始

1. **设置机器** — *激光工具 → 设备设置…*：工作台尺寸、原点位置、`S 最大值`（GRBL 的 `$30`）、
   控制器和加速度。
2. **连接** — 在 *激光* 面板中选择 *USB* 或 *网络*，选择端口或输入 IP 地址，然后点击 *连接*。
3. **绘制或导入** — *文件 → 导入…*（⌘I），或使用左侧工具栏。
4. **设置图层** — 选择图形，点击 *图层* 列表下方调色板中的颜色，然后设置模式、速度和功率。
5. **检查** — *预览*（⌥P）显示加工路径和预计时间。
6. **走边框** — *走边框* 让激光头沿作业外框移动，以确认位置。
7. **加工** — *开始*。*停止*（⌘.）会立即停止控制器。

> [!CAUTION]
> 激光很危险，而且每台机器都不同。请先不放材料、以低功率测试，并且切勿让机器无人看管。

坐标以毫米为单位，从 **工作台左上角** 起算。Lumière 会根据机器配置中的原点位置将其转换为机器坐标。

## 绘制与编辑

### 选择（V）
- 点击选择，Shift+点击加选或减选，在空白处拖动框选。
- 拖动移动（Shift 限制为水平或垂直）；方向键移动 1 mm（Shift：10 mm）。
- 角控制柄等比缩放（Shift：自由缩放），边控制柄沿单轴拉伸。
- **再次点击已选中的图形** 会显示旋转控制柄；按住 Shift 以 15° 为步进旋转。

### 图形
- *矩形（R）、椭圆（E）、多边形（P）、星形（S）*：拖动绘制，按住 Shift 绘制正方形或圆形。
  在编辑节点之前，圆角半径、边数和角数都可以在 *属性* 中修改。
- *直线 / 折线（L）*：点击添加点，双击或回车完成，点击第一个点闭合，Esc 取消。

### 编辑节点（N）
选择一个矢量图形，然后拖动节点或控制柄（⌥ 打破平滑节点的对称），在空白处拖动可选择多个节点，
双击线段插入节点。悬停在节点或线段上时按：**D** 删除、**I** 插入、**B** 断开、**L** 直线、
**C** 曲线、**S** 平滑/尖角、**J** 连接所选的两个端点、**P** 设为起点。方向键将所选节点移动
0.1 mm（Shift：1 mm）。文字需先转换（*编辑 → 转换为路径*，⇧⌘C）。

### 几何（*工具* 和 *排列* 菜单）
| 项目 | 作用 |
|---|---|
| *工具 → 偏移形状…*（⌥O） | 向外或向内，圆角、尖角或倒角 |
| *工具 → 焊接形状*（⌘W）和布尔运算（⌥+、⌥-、⌥*） | 并集、减法（第一个选中的减去其余）、交集、排除 |
| *工具 → 圆角与倒角…* | 所有拐角，或仅节点模式下选中的节点 |
| *排列 → 网格 / 阵列…*（⌥A）、*圆形阵列…* | 按网格或绕中心复制 |
| *排列 → 沿路径复制…* | 沿最后选中的图形复制，可选择沿切线方向 |
| *排列 → 嵌套…*（⇧⌘N） | 将图形排列到工作台上（分组保持在一起），可旋转 90° |
| *修剪形状* 工具（⌘K） | 点击线段，删除至最近的交点 |
| *添加桥接点* 工具 | 点击轮廓添加连接点，Shift+点击移除 |

*编辑* 菜单中还有 *自动连接选定形状…*（⌥J）、*优化所选的形状…*（⌥⇧O）、*删除重复项*（⌥D）、
*选择开放形状*、*选择当前层中的全部形状*、*反选* 和 *转换为位图…*（⇧⌘B）。偏移、布尔运算和简化会
生成由点组成的轮廓（不含贝塞尔曲线）。

### 排列
分组（⌘G）、取消分组（⌘U）、水平 / 垂直翻转（⇧⌘H / ⇧⌘V）、旋转 90°（`;` 和 `,`）、对齐、分布
（按间距或按中心）、*移动选中的对象*（页面中心、四角、四边）、分离（⌥B）、合并（⌥C）、推到正面 /
背面（⇧⌘↑ / ⇧⌘↓）。

## 文字、二维码和条形码

- *文字（T）*：点击工作区，然后在 *文字* 面板中输入：字体、样式、高度、字间距、行间距、对齐。
  *焊接字母*（默认开启）会合并手写体中重叠的字母。
- **路径文字**：选择一段文字和一条路径，然后使用 *工具 → 将文本应用到路径*；*路径起始位置*
  可让文字沿路径移动。
- **可变文字**：`{n}` 序列号、`{date}`、`{time}`。在 *文字* 面板中设置当前编号、每次作业的递增值
  和位数。*CSV 合并…* 可载入 CSV 文件：每一列成为 `{列名}`，每次作业后前进一行。
- *工具 → 创建条形码…* 和 *创建二维码…* 可创建矢量码；请将其放在 *填充* 图层上。

| DXF（ASCII） | 直线、圆弧、圆、椭圆、带凸度的多段线、样条曲线；自动连接线段 | — |
| HPGL（`.plt`） | PU/PD/PA/PR，每支笔一个图层 | — |
| PNG、JPEG、BMP、GIF、WebP | 每像素 0.1 mm，按工作台尺寸缩放 | *文件 → 保存已处理的位图…* |
| G 代码 | *激光工具 → 运行 G 代码文件…* | *文件 → 保存 G 代码…* |

可以把文件直接拖到窗口中。项目文件为 `.lum`（[格式说明](file-format.md)）；如果应用在有未保存

## 图层与加工参数

调色板中的每种颜色都是一个图层。点击颜色可将所选对象指定到该图层（或设置新图形所在的图层）。
列表显示加工顺序（▲▼），*输出* 和 *可见* 用于开关每个图层。

**模式**：*线条*（沿轮廓）、*填充*（在闭合图形内部逐行扫描；间距、过扫描、双向、角度、交叉填充、
*逐个填充图形*）、*同心填充*（逐层向内的轮廓）、*图像*。

**线条选项**：*切缝补偿*、*连接点*、*过切*、*功率渐变* / *渐变起始*、*轮廓方向*、*先切内部*、
*保留起点*、*删除重叠线*、*打点模式*、*虚线切割*。启用电动 Z 轴后：*Z 偏移* 和 *每遍下降*。

**子图层**：*+* 标签页可为相同图形添加另一组参数（例如先填充再描边）。

**材料库**（*窗口 → 材料库…*）：按材料和厚度保存当前图层的参数，稍后应用，并可导入导出为 JSON。

**测试网格**：*激光工具 → 材料测试…*（以及 *间隔测试…*、*对焦测试…*） 在功率、速度、间距、遍数和 Z 偏移中选择两个参数变化，并雕刻标注；
预设涵盖材料、间距和对焦测试。

**更多加工参数**：引入线和引出线（直线或弧线，向外或向内）、每条路径开始和结束时的暂停及其功率（穿透模式）、每个图层的 *恒定功率模式 (M3)*、每遍填充角度增量、*填充多组*、内部形状不加连接点以及 *桥接点切割功率*（部分切割）。图像：*负片图像*、*新闻纸* 和 *素描* 模式，图像面板中的 *增强量*、*增强半径* 和降噪。

**图层菜单**：右键单击图层，可对单个图层、所有图层、除此层以外的所有图层启用、显示或设置气体辅助，或反转；也可移动或删除图层。

## 图像

导入的图片会放到 *图像* 图层。在 *图像* 面板中：亮度、对比度、伽马、反相、*矢量化…*、
*保存处理后的位图…*。*工具 → 将蒙版应用到图像* 只保留闭合图形内部的部分。在图层中设置：*间距*
（分辨率）、*抖动*（阈值、有序抖动、Floyd-Steinberg、Jarvis、Stucki、Atkinson、半色调、灰度）
和 *3D 浮雕：分层数*。

## 预览与时间估算

*预览*（⌥P）绘制作业：切割路径使用其图层颜色，空移为灰色。底部栏显示预计时间（也按图层显示）、
切割和空移长度、进度滑块和播放按钮。在机器配置中设置加速度后，估算会像 GRBL 规划器一样考虑加速度。

## 运行作业

*激光* 面板包含连接、状态和位置、点动面板、*回零（$H）*、*解锁（$X）*、*移动到所选对象*，以及：
- **起点**：*绝对坐标*、*当前位置*（锚点对准激光头）或 *用户原点*（通过 *将原点设在此处* 设置）；
  3×3 网格用于选择锚点；
- *走边框*：沿外接矩形或外包络（*紧凑框选*），激光关闭或低功率开启；
- *开始、暂停、停止*、*仅所选对象*；作业运行时可调整速度和功率；
- 宏和控制台；GRBL 的错误和报警会附带说明。

*定位激光头* 工具会把激光头移动到点击的位置。

**优化设置**（*激光工具* 或 *激光* 面板）：按层、按组或按形状优先级排序（优先级在 *属性* 中设置）、按方向顺序切割、减少空移、最佳起点（尽量选角点）、最佳方向、隐藏间隙。

**更多机器控制**（*激光* 面板）：Z 轴点动、*前往* X/Y 位置和 *获取位置*、按住按钮时 *测试出光*、已保存的位置、*设置结束位置*、*重复* 作业多次、逐个形状或连续走边框。*激光工具 → 中心查找器…* 通过圆形物体边缘上的三个点找到其中心。在预览中，*从此处开始* 和 *从此处保存…* 可从显示的位置继续作业。

## 摄像头

*激光工具 → 管理摄像头…*：选择摄像头，*雕刻校准图案*，按提示顺序点击四个十字，调整
*镜头校正*，*保存校准*，然后点击 *更新图像*，在图形下方显示校正后的画面。摄像头相对工作台不能移动。

**镜头校准向导**（在摄像头窗口中）：将实心圆点网格添加到项目中并雕刻（或打印），平放在摄像头下方，在不同位置多次拍摄，然后点击 *计算校正*：镜头校正会自动设置。之后重新点击四个标记并保存校准。

**9 点对齐**：在摄像头窗口中选择 *9 个标记*，雕刻并点击 3 × 3 的十字网格；对齐采用最小二乘计算，可平均点击误差。*撤销上一个* 可删除最后一次点击。

**摄像头图像与文件**：*摄像头图像设置* 显示摄像头提供的调节项（亮度、对比度、曝光、白平衡、对焦、缩放）；校准可导出和导入为文件；*捕获并描摹* 将校正后的捕获图像添加到项目并打开描摹。

## 打印和切割

*激光工具 → 打印和切割 → 开始向导…*：在图形中选择两个标记，将激光头移动到实物上的每个标记并记录，然后点击
*应用*。作业会被旋转、缩放和平移以对齐，直到停用对齐为止。

## 生产工具

- **机器配置**：多台机器，各自有工作台、原点、控制器、连接方式、旋转轴、扫描偏移、起始/结束
  G 代码和气泵辅助指令。
- **宏**：*激光* 面板中发送 G 代码的按钮。
- **GRBL 设置（$$）**：读取、修改并写入控制器参数；将工作台尺寸、`S 最大值`、速度和加速度
  写入机器配置。
- **项目备注**、**艺术库**（*窗口*）、**旋转轴**（*激光工具 → 旋转设置…*，配合 *起点：当前位置* 使用）。

| *排列* | *自动分组*（形状与其内部的形状）；*沿线条镜像*（⇧⌘M，最后选择直线）；*停靠* 到最近的形状或工作台边缘；*水平 / 垂直向一起移动*（⌥⇧H / ⌥⇧V）；*将激光移到选中区域* 和点动（⌥⌘ 方向键）；橡皮圈轮廓；按绘制顺序前移 / 后移一级（⌘↑ / ⌘↓）；锁定和解锁形状（锁定的形状无法移动）；*两点旋转 / 缩放*（⌘2）：依次点击中心、参考点及其新位置（Shift 同时缩放） |
| *激光工具* | *打印和切割* 的各个步骤（⌥0 到 ⌥4）及重置；用于旋转轴锥形物体的 *锥形变形…* |
| *窗口* | *视图风格*：线框或填充、粗糙或平滑（⌥⇧W）；显示/隐藏侧面板（F12）和各个工具栏；*页面*：工作区上方的标签页，可在一个项目中保存多个设计（图层共享，作业使用当前页面） |
| *帮助* | 许可证、支持论坛、功能请求、在线文档、使用数据（不收集任何数据）、报告问题、支持数据、检查更新、调试日志 |

## 更多编辑与机器选项

- **设置**（⌘,）：吸附与点击容差、方向键步长、自动保存间隔、绘制后选中新图形、滚轮方向、默认字体与高度、可视网格、中心十字、全屏光标、导入时居中与编组、SVG DPI、HPGL 精度。
- **设备设置**（*激光工具*）：连接时回原点、使用 `$J` 或 `G0` 点动、每个 `G1` 都输出 `S`、G0 过扫描、作业超出工作台时警告、红光指示器偏移、Z 反向或相对、启动延时、每次作业前的检查清单，以及可选的测试出光按钮。
- **图层**：图层菜单中的 *设为默认* / *恢复默认*；填充的 *点宽校正*；*编辑 → 按尺寸选择圆…*。
- **圆角** 工具：点击一个角将其倒圆（Shift：倒角），半径在选项栏中设置。
- **素材库**：以文件形式导入和导出素材库。
- **撤销历史** 会为每一步命名（菜单命令，或移动 / 缩放 / 旋转 / 编辑节点）。
- **描摹**：*中心线* 模式沿深色笔画的中线描摹（线稿、手写）。
- **可编辑阵列**：网格和环形阵列与源图形保持关联；*编辑阵列* 可修改，*展开阵列* 将其变为普通图形。
- **图像预设**：内置的起始设置以及您自己的图像和图层设置预设。
- **填充斜坡**（印章）：在 *填充* 图层上，*斜坡* 会在边缘附近降低功率，形成倾斜的侧壁；*倾斜外边缘* 也会处理最外层轮廓（制作印章时请关闭，使边框保持清晰）。
- **材料库链接**：在材料库中，*链接* 将当前图层与某个条目关联；其设置变为只读并跟随材料库（打开项目时也会更新）。↻ 用当前图层的设置替换条目，所有链接的图层随之更新。在图层中点击 *取消链接* 即可重新编辑。
- **测量**（M）：面板显示光标下的图形（或选中的图形）：尺寸、节点、线条、曲线、开放或闭合、周长、面积；光标下的线段：起点和终点、长度、角度，以及曲线的圆心和半径；拖动时显示测量的距离。单位按钮可在毫米和英寸之间切换。
- **扭曲**（路径文字）：使字母弯曲以贴合路径，而不只是旋转每个字母。
- **SHX 字体**：在 *设置* 中选择 AutoCAD `.shx` 字体目录，这些字体会出现在字体列表中。它们是单线字体（开放笔画），适合在 *线条* 图层上快速雕刻。不支持大字体（亚洲字体）。
- **网格阵列选项**：边缘间距或中心距离、填满工作台宽度 / 高度、每行 X 偏移和每列 Y 偏移、平移一半、反转方向、镜像交替行或列、随机方向、分组结果、每个副本的变量文本增量，以及 *创建虚拟阵列*（关闭时为普通副本）。
- **预览选项**：*按照功率调整阴影*、*反转*（黑底白线，便于评估图像雕刻）、显示或隐藏 *空移*，以及 *保存图像…*（Shift：透明背景）。
- **变量文本序列**：*开始* 和 *结束*（到达结束后编号回到开始）、每次作业后 *自动递增*、◀ / ▶ 后退或前进、*重置*。
- **校准轴**（在 *GRBL 设置* 中）：输入请求距离和实际移动距离，计算新的每毫米步数（$100 / $101 / $102）并写入控制器。
- **LightBurn 材料库**：材料库可导入 LightBurn 的 `.clb` 文件（速度由 mm/s 换算，含多个设置的条目成为子图层），也可导出为 `.clb`。
- **LightBurn 项目**：*文件 → 打开*（或拖放）可读取 `.lbrn` 和 `.lbrn2` 文件：图层及其切割设置、矩形、椭圆、多边形、星形、路径、编组、图像，以及文本：若已安装其字体则可编辑，否则转为曲线（使用 LightBurn 随文本保存的路径）。保存时生成 Lumière 项目。
- **导出格式**：*文件 → 导出…* 可根据所选文件类型写入 SVG、DXF（R12，每个图层一个 DXF 图层）或 PDF / AI（PDF 兼容）。DXF 和 PDF 中曲线会被拉平；图像仅在 SVG 中导出。
- **拖动开关**（排列栏右侧）：✥ 移动、⟳ 旋转、⤡ 缩放、▱ 斜切。关闭某项可避免鼠标误操作；数值编辑仍然可用。
- **区域填充（Flood Fill）**（填充图层）：逐个区域完整扫描后再转到最近的下一个区域，而不是逐行横扫整个设计——文字和分散图形的空移大大减少。
- **子图层**：⧉ 将当前显示的设置（主图层或子图层）克隆为新的子图层；子图层可以命名，其标签会显示名称。
- **查找我的激光器**（*激光工具*，或机器设置中的 *向导…*）：在 USB 端口上搜索 GRBL、Marlin 或 Smoothieware 控制器，读取其工作区域和 `S` 最大值，然后询问名称、原点位置和是否自动回原点。网络和 Ruida 设备可在同一向导中手动设置。
- **按速度的扫描偏移**（机器设置）：双向扫描的速度与偏移表，按各图层速度插值；表为空时使用单一扫描偏移。
- **新手模式**（*窗口* 菜单或 *设置*）：切割设置只显示常用选项（模式、速度、功率、次数、间隔、角度、气辅），并隐藏子图层标签、图层默认值和拖动开关。隐藏的设置保留其数值。
- **更多切割选项**：*全局遍数* 将图层及其子图层一起重复；按间距生成桥接，可设每个图形的最少和最多数量；*仅切割时开启气辅*（空移时关闭）；*复制到所有图层*。
- **排列选项**：X / Y 字段使用 3 × 3 参考点（缩放时同样适用）；*偏移* 可同时向两侧并仅处理外部图形；*沿路径复制* 支持固定间距和变量文本增量；*环形阵列* 支持起始角度、可编辑步长、以最后选中图形为中心、分组和变量文本增量。
- **编辑阵列**（*排列*）：*添加到阵列*（选择阵列和新图形）、*从阵列中移除*（选择原始图形）、*复制阵列*。
- **生成轮廓**（*工具*）：在所选内容周围按指定距离生成无孔轮廓；图像按其非白色像素（用于切割贴纸）。
- **恢复圆弧和直线**（*编辑*）：将由许多小线段组成的图形（DXF、PDF、描摹结果）替换为直线和真正的圆弧，可按节点编辑。
- **文本样式与弯曲**：*粗* 和 *斜* 切换到字体的粗体和斜体样式；*弯曲* 将文本弯成弧形（最多整圆，向上或向下）。
- **排版与页面**：排版时内部图形随外框一起移动，放不下的可放到新页面；页面栏可在当前页后插入页面（↳）并导入其他项目的页面（⇩）。
- **作业输出**：*切割最后进行*（优化设置）让线条图层在雕刻之后执行；*全局速度比例*（机器设置）调整所有图层的速度；作业运行时激光面板显示已用时间和预计剩余时间；*激光工具 → 导出作业日志…* 将作业历史（开始时间、时长、行数、错误）保存为 CSV。
- **工具图层与取景**：*T1* 和 *T2*（位于颜色调色板之后）是工具图层，从不雕刻，用于参考和取景。在激光面板中，*取景* 可沿边界框、外壳（橡皮筋）或图形轮廓；*仅工具图层* 只对 T1 / T2 上的图形取景；*图像：非白色区域* 只对图像的绘制部分取景。
- **更多机器选项**：X、Y 反向间隙补偿、输出时交换 X/Y、Z 对焦偏移、连接时的 DTR 信号、连接时读取 GRBL 设置（$$），以及自定义错误和报警说明。
- **移动面板**：*连续点动* 在按住方向键时持续移动（松开即停，最远到工作台边缘）；有 Z 轴的机器保存位置时会记录 Z；*自动对焦* 按钮运行机器设置中定义的对焦 G 代码。
- **旋转轴类型**：滚轮式（滚轮直径）或卡盘式（物体直径），使用 Y 轴（每转 mm）或 A 轴（度），支持镜像输出。
- **描摹窗口**：实时预览在图像上显示结果（*淡化图像*、*显示点*）；*素描描摹* 将照片边缘描摹为线条。
- **二维码和条码**：二维码可包含 Wi-Fi 网络、联系人、电子邮件、电话号码或网址（逐项填写）；一维条码可在下方显示文字；二维码中心可放置 SVG 徽标；同一窗口还可生成 DataMatrix 码（ECC200）。
- **材料测试**：雕刻标题、最后切割的边框（可设功率和速度），以及您自己的预设（保存、删除、导出、导入）。
- **多个材料库**：将文件打开为新材料库，在材料库间切换、重命名或卸载；*合并…* 按重复规则（保留、替换、重命名新条目或原条目）将文件加入当前材料库。链接的图层会在任何已加载的材料库中查找其条目。
- **素材库**：可加载、重命名和卸载多个素材库；*导入文件…* 直接加入 SVG、DXF、PDF 或图像文件（每个文件一个条目）；滑块可调整缩略图大小。
- **外观**（*设置*）：浅色、深色或跟随系统主题；工具栏图标大小；调色板按钮上显示图层编号。
- **控制台窗口**（*窗口 → 控制台…*）：更大的控制台，支持命令历史（↑ / ↓）、清除和保存。
- **页面设置**（页面栏中的 ⚙）：每页的工件尺寸及其在工作台上的位置，以虚线显示。
- **配置文件**（*文件 → 偏好设置 → 配置文件管理…*）：完整的偏好集合（设备、材料库、快捷键、设置），例如每个工作室或每个用户一个；切换会重启界面。捆绑包现在包含所有材料库。
- **3D 浮雕清理**：使用 *3D 浮雕：分层* 时，每隔 N 层进行一次清理扫描，重扫已挖出的区域（或整幅图像）以使底部平整。
- **作业计数**（激光面板）：统计已完成作业；达到 *停止于* 的数量后禁止 *开始*，适合批量生产。
- **面板布局**（*设置*）：侧边面板可放在窗口左侧或右侧，并按所选顺序排列（▲ 上移面板）。
- **工作台外的图形**：*设置 → 忽略工作区域外的图形* 会把完全在工作台外的图形排除在作业之外。
- **斜切**：在旋转模式下（再次点击选区），侧边控制点可斜切选区。
- **导入 PCB**（*文件 → 导入 PCB…*）：添加电路板的 Gerber 和钻孔文件；根据文件名识别每个文件的用途（铜层、丝印、阻焊、锡膏、板框、钻孔）及所在面。选项：用板框反转铜层（隔离雕刻）、镜像底层、将铜层、丝印和阻焊设为 *填充* 图层。每个文件放在各自的图层上，电路板在工作台上居中。
